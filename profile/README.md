## Ce que nous proposons

| | Offre | Pour qui |
|---|---|---|
| 🎮 | **Serveurs de jeu** : Minecraft (Paper, Vanilla, Fabric, Forge, modpacks…), Terraria, Valheim, Rust, ARK, Palworld, Satisfactory et une cinquantaine d'autres | Joueurs, communautés, créateurs |
| 🖥️ | **VPS** Starter, Standard et Pro, en conteneur (LXC) ou en machine virtuelle (KVM) : Debian, Ubuntu, AlmaLinux, Rocky Linux, Fedora, CentOS Stream | Développeurs, bots, petits services |
| 🌐 | **Hébergement web** : sous-domaine offert ou votre propre domaine, HTTPS automatique, accès SFTP | Sites vitrines, blogs, projets |
| 🚀 | **Hébergement applicatif** : déploiement depuis un dépôt Git, HTTPS automatique | Applications web, API |
| 🧩 | **Configuration libre** : VPS, web ou applicatif dimensionné au curseur, prix calculé selon les ressources choisies | Besoins entre deux formules |

Les offres se commandent et se gèrent depuis l'espace client : **[boutique.heberghub.fr](https://boutique.heberghub.fr)**. La boutique est en pré-lancement : pour être prévenu de l'ouverture, **[inscrivez-vous sur la liste d'attente](https://heberghub.fr/liste-d-attente)**.

## Comment ça marche

- **Livraison automatique** : le service est créé dès la commande validée.
- **Gestion depuis le navigateur** : console, fichiers, redémarrage, accès SSH et SFTP.
- **Adresse prête à l'emploi**, en HTTPS : `votre-nom.game.heberghub.app`, `votre-nom.vps.heberghub.app`, `site-xx.web.heberghub.app` ou `votre-app.apps.heberghub.app`.
- **Stock réel** : le stock affiché est calculé sur la capacité réellement disponible de nos serveurs.

## Nos engagements

- 🌱 **Sobriété** : infrastructure hébergée en France, consommation mesurée, conseil d'une formule plus petite quand un service est surdimensionné.
- 🔒 **Sécurité** : chaque client est isolé des autres.
- 💾 **Sauvegardes** chaque nuit.
- 📈 **Transparence** : page de statut publique, supervision des services depuis l'extérieur.
