## Ce que nous proposons

| | Offre | Pour qui |
|---|---|---|
| 🎮 | **Serveurs de jeu** — Minecraft (Paper, Vanilla, Fabric, Forge, modpacks…), Terraria, Valheim, Rust, ARK, Palworld, Satisfactory et une cinquantaine d'autres | Joueurs, communautés, créateurs |
| 🖥️ | **VPS** Starter, Standard et Pro — conteneur ou machine virtuelle, Debian ou Ubuntu | Développeurs, bots, petits services |
| 🌐 | **Hébergement web** — sous-domaine offert ou votre propre domaine, HTTPS automatique, accès SFTP | Sites vitrines, blogs, projets |

Toutes les offres se commandent et se gèrent depuis l'espace client : **[boutique.heberghub.fr](https://boutique.heberghub.fr)**.

## Comment ça marche

- **Livraison automatique** : votre service est créé dès la commande validée.
- **Gestion depuis le navigateur** : console, fichiers, redémarrage, accès SSH/SFTP.
- **Adresse prête à l'emploi** : `votre-nom.game.heberghub.fr`, `votre-nom.vps.heberghub.fr`, `site-xx.web.heberghub.fr` ou `votre-app.apps.heberghub.fr`, en HTTPS.
- **Ressources garanties** : le stock affiché correspond à la capacité réellement disponible, nous ne survendons pas.
